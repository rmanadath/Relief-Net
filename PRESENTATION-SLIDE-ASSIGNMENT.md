## 📌 Important Notes

### **Timing is Critical:**
- ⏱️ **10 minutes MAX** - Practice to stay under
- ⏱️ **2 minutes per person** - Use a timer during practice
- ⏱️ **Leave 30 seconds buffer** for transitions

### **Working URL Requirements:**
- ✅ Must be accessible without login (or provide test credentials)
- ✅ Should work on different browsers/devices
- ✅ All core features must be functional
- ✅ Have backup URL if primary fails

### **GitHub Repository:**
- ✅ Code must be well-organized
- ✅ Unit tests should be visible and documented

## 🚨 Common Pitfalls to Avoid

1. **Going over time** - Practice with timer!
2. **Unclear speaking** - Speak slowly and clearly
3. **Broken demo** - Always have screenshots backup
4. **Missing URL** - Have it on multiple slides
5. **Unequal speaking time** - Ensure everyone gets 2 minutes
6. **Technical jargon** - Keep it accessible
7. **Reading slides** - Speak to audience, not slides
